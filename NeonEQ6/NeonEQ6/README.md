# Neon EQ 6 — اکولایزر ۶ باند با داینامیک EQ

پلاگین VST3 (و AU روی مک) بر پایه JUCE 8. زیرو-لیتنسی (فیلترهای IIR مینیمم‌فاز، بدون اورسمپلینگ و بدون FFT در مسیر صدا).

## بیلد گرفتن

### روش ۱ — خودکار با GitHub (بدون نصب هیچ چیز)
1. یک ریپوی خالی در GitHub بساز و کل این پوشه را داخلش آپلود کن (پوشه‌ی `.github` هم باید باشد).
2. تب **Actions** → **Build Neon EQ 6** → **Run workflow**.
3. بعد از چند دقیقه، از پایین صفحه‌ی همان اجرا، فایل‌های `NeonEQ6-windows-latest` و `NeonEQ6-macos-latest` را دانلود کن.
4. فولدر `VST3/Neon EQ 6.vst3` را کپی کن در:
   - ویندوز: `C:\Program Files\Common Files\VST3`
   - مک: `~/Library/Audio/Plug-Ins/VST3` (برای AU: `.../Components`)

### روش ۲ — روی سیستم خودت
نیاز: CMake 3.22+ و کامپایلر (Visual Studio 2022 یا Xcode).
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
```
خروجی در `build/NeonEQ6_artefacts/Release/` است. (JUCE خودکار دانلود می‌شود.)

## امکانات
- ۶ باند: Bell، Low/High Shelf، Low Cut، High Cut (۱۲/۲۴/۴۸ dB/oct)
- هر باند: Frequency، Gain، Q (فیدر مینیمال)، و Dynamic EQ (Threshold، Range، Attack، Release، Above/Below)
- منبع دیتکتور هر باند: **SELF** (خود ترک) / **SIDECHAIN** (ورودی ساین‌چین DAW) / **LINK** (ترک دیگری که پلاگین روی آن باز است — مثلاً کیک روی باس)
- آنالایزر شبیه Pro-Q 3 با تیلت صفر، سرعت Fast / Normal / Slow
- پنجره ریسایزپذیر؛ اندازه بعد از بستن/باز کردن حفظ می‌شود
- نام ترک از DAW خوانده می‌شود و موقع تغییر نام آپدیت می‌شود (اگر DAW این اطلاعات را بدهد)

## کنترل‌ها
- درگ: تغییر مقدار (Shift = دقیق‌تر) — **دابل‌کلیک چپ**: تایپ عدد — **تک‌کلیک راست**: ریست به پیش‌فرض
- روی گراف: درگ نود = فرکانس/گین، ویل = Q، دابل‌کلیک روی نود = خاموش/روشن، دابل‌کلیک روی جای خالی = فعال کردن باند بعدی

## نکات
- لینک بین ترک‌ها فقط وقتی کار می‌کند که DAW همه‌ی پلاگین‌ها را در یک پروسه اجرا کند (Reaper، Ableton، FL، Cubase، Logic، Studio One معمولاً بله؛ حالت Sandbox/جداگانه‌ی بعضی DAWها نه). جایگزین همیشه‌کارکن: SIDECHAIN.
- اگر ترکی که لینک شده بعد از ترک مقصد پردازش شود، سیگنال کلید یک بلاک (چند میلی‌ثانیه) عقب است — برای دیتکتور داینامیک مشکلی ایجاد نمی‌کند.
- JUCE تحت AGPLv3/لایسنس تجاری است؛ برای استفاده شخصی مشکلی نیست، برای فروش لایسنس JUCE لازم است.
